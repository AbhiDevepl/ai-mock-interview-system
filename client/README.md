# Client

React 19 + Vite frontend for the AI Mock Interview System.

This app uses npm only.

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

The dev server runs on `http://localhost:5173` by default.

## Production Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## Testing

There is no `npm test` script for the client. Run linting with:

```bash
npm run lint
```
